# Role Responsibility Checklist

This checklist template helps new team members understand their role responsibilities and serves as an accountability tool during onboarding. Use this template to track completion of key onboarding activities and ongoing responsibilities for each role.

---

## Product Owner Onboarding Checklist

### Initial Setup
- [ ] Review product vision and strategic objectives
- [ ] Gain access to product backlog and project management tools
- [ ] Meet with key stakeholders to understand their needs
- [ ] Review existing acceptance criteria templates and standards
- [ ] Understand release schedule and deployment processes

### Ongoing Responsibilities
- [ ] Maintain prioritized product backlog
- [ ] Define clear acceptance criteria for all backlog items
- [ ] Attend daily standups and sprint ceremonies
- [ ] Review and accept completed work
- [ ] Communicate stakeholder feedback to the team
- [ ] Make timely decisions on trade-offs and scope changes

---

## Quality Assurance Lead Onboarding Checklist

### Initial Setup
- [ ] Review quality standards and testing strategy
- [ ] Set up access to test environments and tools
- [ ] Understand CI/CD pipelines and automated testing framework
- [ ] Review defect tracking processes and tools
- [ ] Meet with Developers to understand code quality practices

### Ongoing Responsibilities
- [ ] Maintain test strategy and test plans
- [ ] Review and validate acceptance criteria
- [ ] Oversee test case execution and defect tracking
- [ ] Report quality metrics and testing progress
- [ ] Participate in sprint planning and retrospectives
- [ ] Conduct quality reviews before releases

- [ ] Review existing CI/CD pipeline configurations
- [ ] Understand deployment environments (dev, staging, production)

- [ ] Respond to infrastructure incidents

## Project Manager Onboarding Checklist

### Initial Setup
- [ ] Review project charter and objectives
- [ ] Understand team structure and role assignments
- [ ] Gain access to project management tools and dashboards
- [ ] Review risk register and communication plan

### Ongoing Responsibilities
- [ ] Maintain project schedule and timeline
- [ ] Track and report project status
- [ ] Manage risks, issues, and dependencies
- [ ] Facilitate sprint ceremonies and team meetings

- [ ] Ensure project documentation is current

## Using This Checklist

### For New Team Members
1. Work with your manager to customize this checklist for your specific role
2. Complete initial setup items during your first week
3. Use ongoing responsibilities as a daily/weekly reference
4. Track your progress and ask questions when blocked

### For Managers
1. Review this checklist with new team members on day one
2. Schedule check-ins to review progress on setup items
3. Use this as a discussion tool during 1-on-1s
4. Update the checklist based on lessons learned from onboarding

### For Teams
1. Keep this document updated as processes evolve
2. Use it as a reference during role transitions
3. Add role-specific items relevant to your organization
4. Share feedback to improve the onboarding experience
